## 📌 Описание

Модифицированная версия и автономный установщик **Cisco Packet Tracer 8.2.1**, в которой полностью отключено назойливое окно входа в учётную запись Cisco NetAcad / Skills For All.

Идеально подходит для студентов и школьников, у которых недоступна официальная авторизация из-за региональных ограничений, либо для тех, кто хочет просто запускать программу без лишних окон и делать лабораторные работы.

---

## ✨ Особенности сборки

* 🚫 **Без окна логина:** окно авторизации не появляется вовсе — программа стартует напрямую в рабочую область.
* 🌐 **Полноценный интернет:** не нужно отключать сеть перед запуском или настраивать брандмауэр — интернет на компьютере работает в штатном режиме.
* 💾 **Без ограничений:** сохранение проектов (`.pkt`, `.pka`) и симуляция сетей работают в полном объёме.

## 🚀 Варианты установки

### Установка готовой программы (Всё в одном)
> Если у вас ещё не установлен Packet Tracer или вы хотите поставить готовую версию на чистую систему.

1. Перейдите в раздел **[Releases](https://github.com/Gol1kill/Patched-Cisco-Packet-Tracer/releases)** и скачайте `Cisco_Packet_Tracer_8.2.1_by_Gol_1kill_Setup.exe`.
2. Запустите скачанный файл.
3. Нажмите **Enter** для установки по умолчанию (или укажите свою папку).
4. Программа автоматически распакуется и создаст ярлык на Рабочем столе.
